  cd /opt

================================================================================
TROUBLESHOOTING
================================================================================

Brain won't start:
  docker-compose logs brain
  Check: ANTHROPIC_API_KEY set, Docker installed, port 8000 free

Hands won't start:
  Get-Content "C:\Jarvis\logs\hands.log"
  Check: Python 3.11+, port 8787 free, uv sync completed

Tests fail:
  pytest tests/test_gate.py -vv
  Check: All imports working, tiers.py expanded to 50+ tools

Telegram bot not responding:
  Check: TELEGRAM_BOT_TOKEN correct, owner ID set in settings.yaml
  Recreate token: python scripts/setup_keys.py

Morning brief doesn't arrive:
  Check: Jobs scheduled (brain logs)
  Check: Telegram connection
  Manually trigger: python -m brain.jarvis_brain.app ask "morning brief"
